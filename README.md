# NODAYSIDLE

Independent developer from Slovenia building native software, AI-assisted workflows, and practical local-first tools.

My work focuses on:
- native applications
- voice and dictation systems
- notes and knowledge tools
- agent orchestration
- privacy-aware utility software

I prefer structured systems over improvisation:
- deterministic outputs
- reproducible workflows
- contract-driven development
- architectural consistency
- functional before flashy

## What I build

### Voice and input
Practical tools for dictation, transcription, and fast text input across native environments.

### Notes and knowledge
Capture-first systems that turn speech, text, and ideas into structured memory, searchable notes, and visual knowledge surfaces.

### Native utilities
Focused macOS software that solves real problems cleanly, with minimal friction and no unnecessary cloud dependency.

### Agent and workflow infrastructure
Tools that turn product intent into structured execution through contracts, orchestration, and controlled AI assistance.
